# Skills

General-purpose Claude Code skills, hooks and mods, published for anyone to install.

## Language

### Provenance

**Vendored material**:
Third-party material whose content upstream owns; we change only what it takes to run here and keep it comparable to upstream.
_Avoid_: Copied, imported

**Adapted skill**:
A skill forked from a third-party skill that we own from then on; upstream is its provenance, never a source of updates.
_Avoid_: Vendored skill, ported skill
